## Overview

Generative APIs offer seamless access to pre-configured, serverless endpoints of leading AI models.
No need to configure hardware or deploy your own models.

Hosted in European data centers and priced competitively per million tokens used, these APIs enable efficient and scalable integration of AI capabilities into your applications.

Generative APIs let you interact with AI models programmatically to create text, images, or other types of content. Scaleway provides a simple, secure, and scalable way to access popular open-source and commercial models without having to manage any infrastructure.

## Key Features of Scaleway’s Generative APIs

### Access to multiple models

Use popular open-source models hosted and optimized by Scaleway. You can choose the model that best fits your use case (text generation, chat-based interactions, embeddings, etc.).

### Simple, consistent API

All models follow the same general structure (input → output), making it easy to switch models without rewriting your application.

### Managed infrastructure

No GPU provisioning, scaling logic, or model management is required. Scaleway ensures high availability and performance.

### Secure by design

Your requests are handled in a secure environment aligned with Scaleway’s cloud infrastructure standards.

### Predictable performance and billing

You only pay for the requests you make. There is no need to maintain long-running instances or VMs.

### Developer-friendly tooling

SDKs, Quickstarts, and API references make it easy to integrate generative models into any application or workflow.

## Use cases

### Text Generation

Scaleway’s Generative APIs let you generate natural, coherent text using hosted AI models such as Mistral.
With a simple API call, your application can create summaries, emails, product descriptions, or general content drafts without hosting any model yourself.
Because the API abstracts all infrastructure, you do not need to manage GPUs, tune models, or worry about scaling.
This makes AI-powered writing assistance easy to integrate into internal tools, websites, or automated workflows.
It is a straightforward entry point for users who are new to generative AI and want immediate value.

### Document Summarization

Scaleway’s Generative APIs can use Llama 3 to analyze long documents and return summaries or structured information.
This helps teams process reports, logs, transcripts, or knowledge bases without manually reading every line.
The API allows you to submit raw text and receive a simplified version.
This reduces repetitive work and provides faster access to actionable information such as dates or decisions.
Since the heavy processing runs on Scaleway’s infrastructure, even large documents can be handled without additional compute on your side.
